## 硬约束（§4.3）

未达任意一条即视为观感验收失败。

- [ ] **三栏**：左（会话 / 分区 / 工作流）· 中（对话 + Goal / progress）· 右（Markdown Reader）
- [ ] **色态**：pending `#5b8def`、blocked `#d4546a` 在进度/任务态上可辨
- [ ] **忙闲**：左栏或等价位置可见干员/会话忙闲
- [ ] **progress**：中栏有可追踪进度卡
- [ ] **@**：选择后有真实路由效果（非纯高亮）
- [ ] **气质**：深色、信息密度优先、圆形二次元头像、角色感克制

气质对照基准是本机 `/workspace/maid-atelier-target-ref.png`（企划草案点名；**不在本仓库**）。没有该图时，以现 OpenClaw 主线壳为对照，并由管理员主观判定「是同一工台」。

## 界面对照（企划书 §8.1）

- [ ] 三栏比例与信息层级可对照本机参考图与现 OpenClaw 壳，管理员主观「是同一工台」
- [ ] 深色专业壳；无过度角色扮演装饰
- [ ] 圆形二次元头像位存在且可区分干员
- [ ] pending `#5b8def` / blocked `#d4546a` 在进度相关 UI 正确
- [ ] 忙闲状态在左栏（或约定等价位）可见；未知态不伪造成空闲
- [ ] 右栏 Reader 能打开至少一种 MD 来源并完成阅读

P0–P2 右栏只锁可读、可对照。轻量 MD 编辑是否单独立项，见企划书 §9.6，不作为本清单的当前必达项。工台不是 VS Code 克隆。

## 功能对照（企划书 §8.2）

- [ ] 创建并打开会话；消息进出经 gateway 真实可用（P1）
- [ ] @ 选择后消息进入目标干员/会话，有日志或会话证据（P2；对齐 OpenClaw #10 意图）
- [ ] Work / 勾选产生 progress 卡，状态可切换且色态正确（P2）
- [ ] 多 profile 至少 2 干员可切换监督；P3 前可降级为「可切换」（P3）
- [ ] 群房最小监督：能看、能指派、能回读（P3）
- [ ] Pull in 等标明起草的能力若露出 UI，须标 draft，不得默认生产路径（#10 仍为 draft）
- [ ] 安全：默认监听与认证符合 Hermes 基线；无明文密钥进插件前端包
